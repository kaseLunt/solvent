What the product looks like when there's a screen on it

P3 (now) builds everything behind the glass: proven math, the risk daemon, and the public REST/SSE API. The UI is Phase 5 — a Next.js app the roadmap names in four surfaces: Book, Inspector, Observatory, Watch. Below is a concept of each, populated with the real data shapes the P3 API serves.
