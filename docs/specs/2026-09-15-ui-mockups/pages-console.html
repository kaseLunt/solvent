The three pages in the Console register

Cash book leads; the Aave v3 market is a legacy section. Headlines are money-first with a $100 materiality line — dust is counted, never headlined. Each page: the first viewport at full fidelity, then a map of what sits below the fold. Same six parts everywhere: verdict header · identity chips · KPI tiles · chart card · table · evidence drawer.

Assumptions & out of model (drawer)Path assumption, held-flat inputs, what the model excludes, config version, wire notes verbatim.
  • Six shared parts carry every page: verdict header (kicker · headline · dek), identity chips, KPI tiles (crit / warn / ok / dashed-refused), chart card, table with status pills, and one evidence drawer per page.
  • Materiality is a display rule, not a data change: liquidatable counts and Σ always exist in full; the headline and default views read at the $100 line, and the toggle restates the count below it.
  • Refusals stay visible (dashed tile, dimmed row, "Not computed" pill) and never look like zero.
