# Project north star

A publicly deployed, real-mainnet-data risk transparency product for ether.fi Cash that an ether.fi
engineer would recognize as work they need done — strong enough hiring signal to convert a referral
into an interview loop.

## Success evidence

- Live public URL surviving unattended weeks; any Cash borrow position inspectable within seconds
  of chain head.
- Computed health factors continuously matching on-chain `getUserAccountData()` within rounding
  tolerance on a verified sample.
- A stranger completes the full demo path unaided: browse book → inspect address → stress slider →
  Migration Observatory → register alert → receive it.
- Public OpenAPI docs + published npm client; README landing page with recorded 90-second demo.

## Boundaries

- No custody, transactions, wallet auth, or custom contracts — read-only risk surface only.
- Not a multi-protocol product; ether.fi-shaped on purpose.
- Uptime is displayed honestly (status badge), never promised.
