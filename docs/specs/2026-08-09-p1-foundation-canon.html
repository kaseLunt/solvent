00

Doctrine: the register every surface obeys

Every analytical surface reads top-down as: finding → qualification → picture → exact ledger → method → forensics. Nothing that qualifies a picture may render after it; nothing exact may interrupt the reading line; nothing that carries meaning renders below 12px — structurally (§03).
Mono marks exactness

If it is monospace, it is verbatim: an address, a block number, an exact value, a formula, a wire code, raw evidence. If it is sans-serif, it is for a human. The typeface itself is a provenance claim — mono’s presence carries information instead of noise.

Quiet is the healthy state

Fresh and healthy render as the absence of signal — measured ink, no green celebration. Color appears when the instrument has something to say: amber for degraded knowledge (stale · refused · withheld · projected), coral for adverse. A fill is the final escalation, never decoration.

Refusal is ink, not absence

A refused value is visible, counted, and named — by its plain cause first, its wire code second. An unknowable never dresses as zero. Live transport never vouches for snapshot age. Engine books are never summed.

Usage law
  • Text always uses the -text grade; SVG marks, borders, and tints use the fill grade. In dark the two grades share values, so components reference --*-text for text unconditionally and stay lawful in both themes.
  • --ink-3 never carries a value, a state, or a finding, and never sits on chip or tinted grounds. Refused-row text is always --ink-2 (dark refused tint measures ink-3 at 4.04).
  • Semantic color never travels alone: every ok/warn/crit use pairs with text, an icon, or a shape.
  • Green is rationed: --ok means comfortably healthy. Fresh data, completed lookups, and near-threshold positions never render green.
  • Chart series identity uses accent + ink tiers, never ok/warn/crit; status colors are reserved for state.
  • Data surfaces are flat: --shadow is lawful only on overlays (readouts, popovers, drawers rendered above content) — never on cards, figs, or tables.

Freshness: four tiers derived, not chosen

Every threshold is a theorem about the pipeline’s own constants. 60s price samples (D-012), 180s budget, 360s ceiling — past it an input is REFUSED, never served stale — and a 5,580s worst-case Debt Manager sweep. A healthy pipeline bounds served-batch age at ~62s + pass time. Status: ratified-pending-owner — until the owner ratifies with the styleguide approval, the age renders WITHOUT severity styling (age always shows; tiers stay dormant).

Numbers: three layers, one truth, a visible scent

Every number exists in three registers — human in the reading line, exact on demand, raw in evidence — and they are the same number. Rounding is presentational; the exact string is the value of record. And the exact layer is never a hidden drawer: any human value whose exact string differs from what is shown wears the visible affordance below.
