## Deviations from the brief, with reasons

1. **`rowsOf` builds the `DotPlotRow` union by arm.** The brief's single object literal (`tenths: r.shareTenths` with a computed tone) cannot satisfy the kit's discriminated union and used `?? 0n` for the tone; a non-point is now explicitly `tenths: null, tone: "refused"`, and a point whose `shareTenths` is somehow null (impossible by the lib's construction) is a refused track that says "no share" rather than a dot at zero.
2. **Words are per engine.** The brief's `rowsOf` printed "of the Cash book" and "not modelled for Cash" for the legacy rows too. Decision 6 (engines never conflated) forbids that: the legacy plot says "of the legacy book" / "not modelled for the legacy market". The not-covered word is said once (the lib's reason "not modelled" is not appended in brackets after the engine-specific word).
3. **Freshness is worded, not printed raw.** `SetRunEvaluation.freshness` has four values (`still_newest`, `superseded`, `newest_is_older`, `none_servable`); the brief's finding would have printed the wire token. Each has a sentence and a pill word; the notice element keeps the brief's id `lab-compare-superseded` for all three non-newest states and carries `data-freshness`.
4. **The finding says "at batch N (…)" rather than "today (batch N, …)".** "Today" would be a false claim once the evaluation is superseded.
5. **The legacy plot has its own measured frame.** The brief reused the Cash frame's `width` inside a padded `<details>`, which would overflow by the padding; a second `useMeasuredWidth` measures the fold's own frame (it measures on open via ResizeObserver).
6. **`.plotFrame > svg { max-width: none }`.** The kit's `.chart` sets `max-width: 100%` and `DotPlot` has no `viewBox`, so in a frame narrower than the plot's 480 px minimum the SVG would clip its right column instead of the frame scrolling (the `useMeasuredWidth` law). The override is scoped to this page's frame; the kit is untouched.
7. **Running finding pluralises** ("Evaluating 1 scenario…" is reachable via `?scenarios=a,ghost`).
8. **Idle body says "No plot yet."** rather than "No plot: nothing here is a share." (kept for the failed state).
9. **Pins use the helper's counters** (`counts.sets()`, `counts.posted()`, `setDelayMs`) instead of the brief's ad-hoc routes; the brief's own set route would not have answered the CORS preflight. The brief's withheld fixture (`covered_engines: []` with a withheld engine) is contradictory under the lib's census law, so C25 withholds with the engine still covered — the shape the wire actually produces.
10. **`dispatchNotice` deleted** per decision 7 (in this commit). Compare does not write `?scenarios=` (the brief does not ask it to; decision 2 was conditional) — see concerns.
11. **The two `app/lab` files were formatted with prettier** (defaults); lib/tests files were edited in place, unreflowed.

## Concerns

- **Compare does not write `?scenarios=` to the URL.** A comparison is therefore not linkable from the page itself. Writing it is not free: the URL is also the deep-link input, and a `?scenario=` already present (a single deep link the reader then compares from) would turn the written URL into the "both params" conflict and render a false "NOTHING was run" notice. Needs a small design ruling (which param wins on write; delete `scenario` on Compare?) — a Plan 3b item.
- **A zero share is toned `warn`** (the brief's mapping): the two demo scenarios with a measured zero delta render as amber dots at the axis. Amber for "no change" is arguable; `ok` would read as "good", which is also a claim. Taste question for review; a one-line change.
- **The card shows every result the set returns**, not only the ticked ids; the demo mock returns four results for two asked ids and C24 pins four rows. Against a real server the wire's results match the request; if a wire ever returned more, the card would show them without comment.
- **`DotPlot` clipping in narrow frames** is a kit trait (no `viewBox`, `max-width: 100%`), patched here at the page. If Task 14's screenshots or another page mount a `DotPlot` in a scrolling frame, the kit should own the fix instead.
